# PowerModeManager Privacy Notice

PowerModeManager has no analytics, user accounts, or feature that sends user data to a remote service. The app reads macOS power settings and changes them only after the user authorizes the operation.

## Local files

- Settings backups are stored in `~/.powermode-backups`.
- If monitoring log storage is enabled, events are written to `~/.powermode-monitor.log`.
- If the user saves a diagnostic report, the JSON file is created on the Desktop by default and may include the Mac model, host name, and power settings.

Review a diagnostic report before sharing it. These local files may remain after the app is uninstalled and can be deleted manually.

## Website and support

The official website is a static GitHub Pages site and does not load analytics scripts. GitHub may process site access information as part of its hosting service; this is separate from app data stored locally on the Mac.

For a privacy question or product issue, use [public GitHub Issues](https://github.com/powermodeapp/PowerModeManager-Releases/issues). Issues are visible to everyone. Write in English or Korean and do not attach an unreviewed diagnostics report.

For a suspected security vulnerability, use [private vulnerability reporting](https://github.com/powermodeapp/PowerModeManager-Releases/security/advisories/new) instead of opening a public issue.

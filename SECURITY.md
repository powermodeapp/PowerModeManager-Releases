# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/powermodeapp/PowerModeManager-Releases/security/advisories/new). Do not include vulnerability details in a public issue.

The maintainers will review the report and coordinate a response before public disclosure. General product problems belong in [public Issues](https://github.com/powermodeapp/PowerModeManager-Releases/issues).
